# Xinetic Desktop Theme

The visual theme for Xinetic.OS 2.0.

## Colour Palette

- Graphite: #101419
- Charcoal: #191F26
- Electric Cyan: #00DCFF
- Silver: #E1E8EE

## Components

- KDE Plasma colour scheme
- Desktop panel styling
- Window decoration styling
- Application styling

Initial colour scheme created.
