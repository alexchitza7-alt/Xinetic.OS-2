# Xinetic Desktop Theme

The visual theme for Xinetic.OS 2.0.

## Colour Palette

- Graphite: #101419
- Charcoal: #191F26
- White: #FFFFFF
- Silver: #C8D0D8

## Components

- KDE Plasma colour scheme
- Desktop panel styling
- Window decoration styling
- Application styling

## Design Direction

A clean, modern interface using dark graphite surfaces, white details, and silver highlights.

## Status

Initial KDE colour scheme created.
Further KDE Plasma integration is planned.
